### Model client streaming

`model_client.py` exports two functions for LLM inference:

- `generate(system_prompt, user_prompt) → str` — synchronous, returns complete response
- `async def generate_streaming(system_prompt, user_prompt)` — async generator yielding text chunks

Both are OpenAI-compatible (work with Ollama and vLLM). The async generator follows the OpenAI SSE wire format and can be interrupted mid-stream via Python's async context manager semantics (aclose()).
~~~

**Rationale**: The async streaming function is important for Phase 2 and later streaming-capable regions, but is not documented in CONTEXT.md.

Compatible with Ollama and vLLM.\n\n    The caller can break out of the async for loop at any time; Python will\n    call aclose() on this generator, which closes the httpx connection and\n    stops server-side generation."

**Factual claims**:
- Function signature: `async def generate_streaming(system_prompt: str, user_prompt: str)`
